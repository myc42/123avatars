# 123avatars

Générateur d'avatars illustrés open source, inspiré de [Humation](https://humation.app/) et de diverses références visuelles, conçu pour offrir une représentation authentique des traits africains.

---

## Pourquoi ce projet ?

J'avais besoin d'un outil capable de générer des illustrations d'avatars dans un style graphique précis, mais je ne trouvais pas d'options représentant fidèlement les traits africains. J'ai donc créé **123avatars** en m'inspirant de Humation et de plusieurs autres sources visuelles, puis j'ai décidé de le publier en **open source** pour que toute personne souhaitant l'utiliser ou le faire évoluer puisse y accéder librement.

---

## Fonctionnalités

* **Architecture ultra-simple (Single-Page HTML)** : l'ensemble du projet tient dans une seule page HTML — aucune configuration complexe ou architecture multi-pages requise.
* **Représentation des traits africains** : variété de coiffures, traits du visage, carnations et détails inspirés de multiples références visuelles.
* **Exports multi-formats** :
  * **PNG** : pour une utilisation directe sur le web ou les réseaux sociaux.
  * **SVG** : rendu vectoriel redimensionnable à l'infini.
  * **Style crayon** : rendu esquisse/dessin au trait.
